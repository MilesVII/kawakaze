Max count of messages to send to API. 0 to send all (not recommended due to potential context overflow)
The tail is a cost-saving measure, but most providers (including everything on OpenRouter) cache repeated prompt prefixes, so a short tail rarely saves much. Its main purpose is to keep small-context models from overflowing.
When enabled, the tail is stretched back to the message the latest summary is attached to. When disabled, the summary is only sent while that message is still inside the tail, possibly losing it.
OOC notes (hold the send button to append one) are sent as system messages by default. Some local chat templates only accept a system message at the very start; enable this to send notes as user turns prefixed with "OOC:" instead.
Kawakaze is a hosted edition of Ägir. Chats, personas and provider keys stay on this device.
